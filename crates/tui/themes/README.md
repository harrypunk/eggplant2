# Theme resources

`default.toml` preserves Eggplant's original built-in palette in Helix theme format.

The following files are unmodified resources from Helix at revision `079a789e8cb08ead67f19e1971a1b7438b37354b`:

- `tokyonight.toml`: `runtime/themes/tokyonight.toml`, by Paul Graydon according to its source header.
- `catppuccin_mocha.toml`: `runtime/themes/catppuccin_mocha.toml`; its header points to <https://github.com/catppuccin/helix> as the upstream theme repository.

Source: <https://github.com/helix-editor/helix/tree/079a789e8cb08ead67f19e1971a1b7438b37354b/runtime/themes>

The Helix license is retained in `licenses/helix.LICENSE`. Source headers are kept intact. Review upstream and theme-specific notices when importing additional resources.
